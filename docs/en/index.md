Welcome to the official `afrog` documentation.

`afrog` is a security tool for vulnerability verification, PoC authoring, and integration development. The documentation is organized into **four handbooks** — start with the one closest to what you are doing right now.

## Four handbooks

### 1. User Guide

What `afrog` is, how to install it, the CLI, configuration and output, plus practical tips.

[Go to the User Guide →](./user-guide/01-overview.md)

### 2. PoC Authoring Guide

Start from your first PoC, then move on to syntax, helper functions, `requires` gating, `brute`, OOB, and TCP/SSL.

[Go to the PoC Authoring Guide →](./poc/01-quickstart.md)

### 3. SDK Usage Guide

Embed `afrog` into your own Go program: sync and async, handlers and streams, configuration and API reference.

[Go to the SDK Usage Guide →](./sdk/01-quickstart.md)

### 4. Curated PoC

Connect to the curated PoC service: licensing, mounting, updating, and enabling it in `afrog`.

[Go to Curated PoC →](./curated/01-overview.md)
