Welcome to the official `afrog` documentation.

`afrog` is a security tool for vulnerability verification, PoC authoring, and integration development. The documentation is organized into **five handbooks** — start with the one closest to what you are doing right now.

## Five handbooks

### 1. User Guide

What `afrog` is, how to install it, the CLI, configuration and output, plus practical tips.

[Go to the User Guide →](./user-guide/01-overview.md)

### 2. Web Console

Run scans and watch progress in a browser, review and manage results, author PoCs, and use scheduled scans, multi-instance dispatch, and AI assistance.

[Go to the Web Console handbook →](./web/01-overview.md)

### 3. PoC Authoring Guide

Start from your first PoC, then move on to syntax, helper functions, `requires` gating, `brute`, OOB, and TCP/SSL.

[Go to the PoC Authoring Guide →](./poc/01-quickstart.md)

### 4. SDK Usage Guide

Embed `afrog` into your own Go program: sync and async, handlers and streams, configuration and API reference.

[Go to the SDK Usage Guide →](./sdk/01-quickstart.md)

### 5. Curated PoC

Enable curated PoCs (the subscribed feed): getting a license, configuring it, and everyday use with automatic updates.

[Go to Curated PoC →](./curated/01-overview.md)
