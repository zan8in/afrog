## 资产

任何一次扫描的目标都会**自动沉淀为资产**（零维护）；也可以手工新增或导入。

| 能力 | 说明 |
| --- | --- |
| 自动沉淀 | 扫过即入库，不用手动登记 |
| 标签与收藏 | 给资产打标签、收藏常用目标 |
| 扫描痕迹 | 记录 `last_scan_at` 与 `last_task_id`，方便回头看「这个目标上次什么时候扫过」 |
| 带去扫描 | 选中一批资产可直接带到[扫描页](./02-scan.md)开扫 |

资产是目标的**唯一真源**：项目、扫描、计划任务都只引用资产，不再各自存一份目标。

## 项目

项目把一组资产组织成一个**业务单位**，是扫描历史的归属依据。

- **扫描历史归属**：从项目发起的扫描会登记到该项目名下，项目的台账筛选与项目报告里能看到对应命中。
- **复测对比的依据**：项目是找到「上一次扫描」的根据，因此只有从项目发起扫描才能做[复测对比](./03-tasks.md)。
- **按项目统计与导出**：命中可按项目聚合统计，也支持按项目导出报告。

### 典型用法

1. 把同一业务系统的资产归到一个项目；
2. 从项目发起一次「标准漏扫」；
3. 修复后再从项目发起一次「复测对比」，看新增 / 已修复 / 仍未修复。

## 与扫描的关系

- 手输目标的扫描：目标会沉淀为资产，但不归属任何项目。
- 从项目发起的扫描：以**项目引用的资产**为唯一目标来源（手输目标不参与），保证归属干净、不污染项目数据。
