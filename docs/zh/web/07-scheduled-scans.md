## 什么时候用

当你需要**定时/周期性地重跑同一份扫描配置**（例如「每天对某批资产跑一遍高危 PoC」），就用计划扫描，而不是每次手动发起。

> 计划扫描是会员能力。普通用户可进入页面看到上锁预览。

## 配置一份计划

在「计划扫描」页新建一份计划，配置项与一次手动扫描基本一致：

- **目标**：选择要周期性扫描的资产或项目；
- **PoC 与参数**：使用与[扫描](./02-scan.md)相同的参数口径（意图、并发、速率、超时、PoC 范围、级别等）；
- **执行节点**（会员）：可选地把这次扫描交给某个在线同伴节点执行，见[多实例与远程派发](./08-cluster.md)；
- **计划**：设置触发的时间/周期。

计划配置保存在 `~/.config/afrog/schedules.json`。

## 到点会发生什么

- 到点后服务端按时把这次扫描交出去执行，和手动扫描走**同一条执行路径**。
- 计划触发的任务会出现在「扫描」页的任务列表里，并带**「计划」来源标记**；打开时会把开扫以来的过程事件补发一次，所以 Web 探测、端口、命中都不会缺。

## 回看上次结果

计划扫描的「查看上次结果」会跳到**按任务筛选的[漏洞台账](./05-ledger.md)**视图，方便对照每次巡检的命中变化。
