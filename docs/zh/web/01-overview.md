## 这是什么

`afrog` 除了命令行，还内置了一个 Web 控制台。它和 CLI 共用**同一套引擎与 PoC**，区别只在交互方式：把一次性的命令行扫描，变成**可常驻、可看过程、可留痕、可回溯**的图形工作流。

一句话：**命令行适合一次性、脚本化；Web 控制台适合持续运行、看过程、多人看结果。**

## 启动与登录

```bash
afrog -web
```

默认监听 `:16868`。要改地址，在 `afrog-config.yaml` 里配置：

```yaml
server: 127.0.0.1:16868
```

启动时终端会打印本次访问密码：

```text
[INF] Web访问密码: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

- 密码**每次启动随机生成**，浏览器打开控制台后用当天这串密码登录。
- 登录态是一枚 JWT，令牌里区分 `curated`（会员）与 `free`（免费）两档角色。
- **关闭终端就等于关掉服务**，请把服务放到常驻环境运行。

> 注意：服务本身**没有内置 HTTPS**。要暴露到公网，请放在反向代理之后，并自行加上 TLS 与访问控制。

## 数据放在哪

| 内容 | 位置 |
| --- | --- |
| 扫描命中、资产、项目、漏洞台账、任务记录 | `~/.config/afrog/afrog.db`（SQLite） |
| 定时/计划扫描的配置 | `~/.config/afrog/schedules.json` |

命中结果是长期数据，会一直保留；任务记录只保留**最近 200 条**用于界面历史列表。更早的任务仍可按任务 ID 在漏洞台账里查到命中结果。

## 界面导航

左侧导航按用途分组：

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 工作台 | 概览 | 数据总览、最近动态与多实例状态 |
| | 扫描 | 发起扫描、查看进行中与历史任务 |
| | 计划扫描 | 定时/周期性重跑同一份扫描配置（会员） |
| | 项目 | 一组资产 + 其扫描历史的组织单位 |
| | 资产 | 扫过的目标自动沉淀，可打标签、收藏 |
| 结果 | 漏洞报告 | 按任务/关键字/级别筛选命中记录 |
| | 漏洞台账 | 命中的状态流转与备注（会员） |
| 数据 | 漏洞库 | 浏览内置/精选 PoC 与漏洞详情，编写自己的 PoC |
| | 会员中心 | 会员配置与激活、精选 PoC 挂载状态与更新 |
| 其他 | 设置 | 账号、通知、OOB、AI、服务信息 |

## 权限与会员

- 控制台是**单用户**形态：一个访问密码，没有多账号体系。
- 标记为会员能力的页面（计划扫描、漏洞台账、集群、导出等）普通用户**仍可进入**，但页面内为上锁预览，升级后即解锁；后端也会二次校验，前端可见性只是引导。
