## 漏洞库

「漏洞库」用于浏览与检索 PoC，来源分为：

| 来源 | 说明 |
| --- | --- |
| 内置 | 随 afrog 发布的内置 PoC |
| 精选 | 会员（Curated）拉取的精选 PoC |
| 我的 | 你创建/另存的 PoC（可编辑、可删除） |
| 本地 / 追加 | 本地目录或追加目录里的 PoC |

列表支持按级别、标签、作者、时间、收藏等维度筛选与关键字搜索。点击任意一条进入**漏洞详情页**。

## 漏洞详情

详情页展示该 PoC 的完整元信息：

- 名称、级别、来源、CVE / CWE / CVSS
- **漏洞详情**（description）、**参考链接**（reference）
- **影响版本**（affected）、**修复建议**（solutions）
- **PoC 源码**（YAML），可复制、下载
- 顶部的复制 PoC ID、编辑（仅「我的」）、另存为我的副本、删除

## 编写 PoC

「新建 PoC」与编辑「我的 PoC」共用同一个全屏编辑器：

- 左侧写 YAML，右侧实时显示**校验结果与元信息预览**；
- 顶部有「插入模板」，可一键插入基础 HTTP、多规则、OOB、TCP、brute、raw 等骨架；
- 保存走创建或更新接口，保存成功后跳到该 PoC 详情页。

### 编辑器能帮你什么

编辑器围绕 **afrog PoC 规范**提供辅助，而不是靠记忆硬写：

- **自动补全**：在 `info` / `rules` / `request` / `brute` / `expression` / `set` 等不同位置，提示对应字段、枚举与表达式变量、函数；
- **悬停文档**：把鼠标放到字段名、内置变量或函数上，显示说明、参数与示例；
- **实时结构校验**：边写边校验，右侧列出问题，**点问题可跳到出错行**；
- **模板与片段**：常见场景直接插入可改的骨架。

字段、内置变量与函数的权威来源是 afrog 的 PoC 规范与引擎实现；语法细节见 [PoC 语法参考](../poc/02-syntax.md)，从零开始看 [写出你的第一条 PoC](../poc/01-quickstart.md)。

## 与扫描的关系

编辑器负责「写」，[扫描](./02-scan.md)的「PoC 与范围」负责「用哪些」。两者使用同一套 PoC 来源，因此写好的「我的 PoC」会立刻出现在扫描的 PoC 选择器里。
