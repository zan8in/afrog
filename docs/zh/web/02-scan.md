## 目标输入

在「扫描」页输入目标即可开始。目标框会自动识别并归一化下面这些形态，一行一个或逗号分隔都可以：

- URL：`https://example.com/login`
- 域名：`example.com`
- IP 与带端口：`192.168.1.10:8080`
- CIDR：`10.0.0.0/24`

也可以不手输，直接从[资产](./04-assets-projects.md)页选中一批目标带到扫描页，或从[项目](./04-assets-projects.md)发起（以项目资产为唯一目标来源）。

## 扫描意图

扫描意图决定跑多少 PoC：

| 意图 | 适用场景 |
| --- | --- |
| 快速验证 | 单目标、高危 PoC、几十秒出结论 |
| 标准漏扫 | 全量 PoC、可后台运行、覆盖面优先 |
| 复测对比 | 与该项目上一次扫描自动比对，看修没修（会员） |

> 「复测对比」需要任务有归属项目：项目是找到「上一次扫描」的依据，从项目发起扫描才能做对比。

## 高级参数

需要更细的控制时展开「高级」，这里的参数与命令行完全一致：

- 并发、速率、超时、重试
- 代理、请求头
- OOB 带外检测
- 端口扫描、Web 探测与指纹
- PoC 范围（来源 / 手动选择 PoC / 关键字）
- 漏洞级别过滤

其中「PoC 与范围」这一组可以**手动选择要跑哪些 PoC**（可搜索、可多选），不选则按严重等级自动推荐。

## AI 推荐参数

粘贴目标后，点「AI 推荐参数」，AI 会结合目标的规模、类型（URL / IP / CIDR / 域名）与当前意图，给出 2~4 条推荐理由，并把并发、速率、超时、智能并发、端口扫描、Web 指纹、严重级别等整理成一份可直接采用的配置。抽屉底部点「应用推荐参数」即写回表单（之后仍可手动微调）。

- **只上传目标画像**：发送的是目标数量、类型分布与最多 20 条样例，不是完整目标清单。
- **参数有边界**：越界数值会被夹回允许范围，非法级别会被丢弃。
- **只覆盖推荐项**：模型没给出的字段保持你当前的设置。
- 同一批目标重复打开走缓存；未配置模型时会引导到「设置 → AI 辅助」。

详见 [AI 辅助](./09-ai.md)。

## 选择执行节点（会员）

「扫描」工作台有一个「执行节点」选择器（列出在线同伴，默认本机）。选中某个节点后点「开始扫描」，这次扫描就交给该节点执行，详见[多实例与远程派发](./08-cluster.md)。

## 开始扫描

点「开始扫描」，前端会把目标、PoC 范围与参数组装成一次扫描请求提交到服务端：

- 服务端立即登记任务并返回任务 ID，前端订阅事件流实时展示。
- 任务有**并发上限**（默认 6，可用环境变量 `AFROG_MAX_RUNNING_TASKS` 调整），超出的任务会排队执行。

提交后进入任务列表与详情，见[任务与实时过程](./03-tasks.md)。
