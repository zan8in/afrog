## 设置里有什么

| 分区 | 内容 |
| --- | --- |
| 账号 | 登录与安全相关说明（单密码登录） |
| 通知 | 命中/收尾消息的推送渠道与日志 |
| OOB | 带外检测的反连凭据 |
| AI 辅助 | 模型接入配置与连通性测试 |
| 服务信息 | 版本、实例信息等 |

## 账号与安全

控制台使用**单访问密码**登录，密码每次启动随机生成并打印到终端。没有内置 HTTPS，对外暴露请放在反向代理之后并自行加 TLS 与访问控制。安全边界见[总览](./01-overview.md)。

## 通知

可以配置命中与任务收尾的消息推送到团队渠道（如钉钉 / 企业微信），并查看发送日志、对失败的发送进行重试。通知按任务去重与限流，避免刷屏。

> 通知属于会员能力。

## OOB 带外检测

OOB（带外）用于验证**无回显漏洞**：先让目标主动访问一段外部地址，再通过 OOB 平台查询是否收到访问记录。在设置里填写反连配置（`reverse` 段），保存后写回 `afrog-config.yaml`，下次起扫描子进程时生效。

OOB 在 PoC 中的写法见 [OOB 带外检测](../poc/06-oob.md)。

## AI 辅助

填写模型服务的地址、Key 与模型名，保存即生效（无需重启）。保存本身**不会调用模型**；填好后可点「测试连接」发一次极小请求，确认地址 / Key / 模型名确实可用。额度与三项能力的说明见 [AI 辅助](./09-ai.md)。

## 服务信息

展示当前服务版本、实例标识等运行信息，便于确认部署与排查环境问题。

> 部分设置会**写回配置文件**（如 OOB 的 `reverse` 段、AI 的 `ai` 段），字段字典见[配置文件说明](../user-guide/05-configuration.md)。
