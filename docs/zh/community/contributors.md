每一条高质量 PoC，都在帮助更多使用者更快、更准确地完成漏洞验证。

`afrog` 会持续保留对 PoC 贡献者的公开致谢。当前荣誉展示以仓库根目录 [README 的 `PoC Contributors`](../../../README.md#poc-contributors) 为主，同时这里作为文档站内的稳定入口。

## 说明

- 历史 PoC 贡献者会继续在 README 中保留展示。
- 后续如果 README 再做结构优化，也应保证这里与 README 至少有一个权威荣誉入口始终可访问。
- 如果贡献展示需要补录或修正，建议在 Issue 或 PR 中说明。
